# Imagens das questões

Coloque nesta pasta as imagens usadas nas questões. Nomeie cada arquivo com o ano e o número da questão, por exemplo `2023-questao-24.png`. Para questões de inglês ou espanhol, inclua o idioma no nome, como `2023-questao-01-ingles.png` ou `2023-questao-01-espanhol.png`.

Ao adicionar ou remover imagens, atualize também o `manifest.json` com os nomes dos arquivos `.png`. O simulador usa esse índice para relacionar os arquivos às questões.
